# Provenance and authorship

This project is developed openly about who did what, because it is
intended to become a public open-source project.

- The initial design and implementation (v0.1.0, 2026-10-28) were drafted
  by Anish Pentyala's Instinct assistant at his direction, as part of an
  ongoing extracurricular software effort he asked it to run.
- Anish Pentyala directs the project: goals, scope, review of releases,
  and decisions about publication. His own contributions (design
  decisions, testing, code he writes or modifies, review) are recorded in
  `WORKLOG.md` as they happen.
- Nothing here claims adoption, users, stars or impact that did not
  happen. Any metrics mentioned in future releases must come from real
  data with dates.
- If this project is ever submitted anywhere (competitions,
  applications, third-party repos), the assistant's role must be
  disclosed the same way it is here, and any venue's rules about
  AI-assisted work apply.
